## 1. MVP 성공 기준 (Definition of Done - DoD)

서비스가 MVP로서 **"정상 완성"**되었다고 선언할 수 있는 5대 최소 기준은 다음과 같다.

### 1.1 [E2E 포트폴리오 탐색 & AI 매칭]
* 구직자가 메인 화면에서 설문(비전공 + 기획 직무 등)을 선택했을 때, 관련 포트폴리오 추천 목록이 1초 이내에 정확히 렌더링되어야 한다.

### 1.2 [모바일 인터랙티브 뷰어 정상 작동]
* 375px 모바일 화면에서 장표 이미지를 스와이프하여 넘길 수 있고, 하단 바텀 시트를 열었을 때 해당 장표의 AI 로직 분석 주석이 텍스트 깨짐 없이 온전히 읽혀야 한다.

### 1.3 [AI 챗봇 정상 응답 및 가드레일 엄격 작동]
* **포트폴리오 관련 질문 입력 시:** 해당 장표의 기획 의도를 반영한 답변이 실시간 스트리밍으로 출력되어야 한다.
* **무관한 질문(예: "주식 추천해줘", "날씨 알려줘" 등) 입력 시:** 어떠한 임의 답변도 생성하지 않고, **"죄송합니다. 포토폴리오와 관련된 질문에만 답변할 수 있습니다."** 표준 문구를 정확히 반환해야 한다.

### 1.4 [관리자 페이지 접근 제어 검증]
* `ADMIN_EMAILS`에 등록되지 않은 일반 사용자나 비로그인 사용자가 `/admin` URL로 접근 시 즉시 차단(403 또는 홈 리다이렉트)되어야 하며, 인가된 관리자 계정만 포트폴리오 등록 대시보드에 접근할 수 있어야 한다.

### 1.5 [비용 및 배포 안정성]
* Vercel 프로덕션 환경에 성공적으로 배포되고, Supabase 및 Google AI Studio 무료 티어 한도 내에서 $0 비용으로 오류 없이 구동되어야 한다.

## 2. 인수 테스트 체크리스트 (Acceptance Test Checklist)

- [ ] 비로그인 상태에서 `/admin` 접속 시 403 리다이렉트 확인
- [ ] 관리자 이메일로 로그인 후 `/admin` 정상 렌더링 확인

- [ ] 챗봇에 "내일 비 와?" 질문 시 `"죄송합니다. 포토폴리오와 관련된 질문에만 답변할 수 있습니다."` 출력 확인
