## 2. 상세 기능 명세

### 기능 1: 내 상황 입력 기반 AI 유사 합격자 매칭 (AI Profile Matcher)
* **기능 ID:** `FEAT-01`
* **우선순위:** **필수 (P0)**
* **설명:** 구직자의 출신 배경(비전공/전공), 희망 직무(PM/개발/디자인), 목표 기업 규모, 보유 프로젝트 수를 입력받아 가장 유사한 합격자 포트폴리오를 추천.
* **사용자 시나리오:**
  1. 유저는 메인 화면의 `[30초 맞춤 합격작 찾기]` 모달을 연다.
  2. 직무(예: '서비스 기획'), 배경(예: '비전공/문과'), 프로젝트 경험(예: '부트캠프 1회')을 선택하고 매칭 버튼을 누른다.
  3. 시스템이 유사도 알고리즘을 통해 나와 조건이 가장 일치하는 합격 포트폴리오 Top 3를 즉시 카드 형태로 추천한다.
* **세부 요구사항:**
  * 비로그인 유저도 1회 무료 체험 가능 (회원가입 시 상세 필터링 및 북마크 해금).
  * 매칭 결과 카드에 '유사도 점수(예: 94% 매칭)' 및 핵심 합격 포인트 뱃지 노출.

### 기능 2: AI 기반 포트폴리오 로직 분석 뷰어 (AI Logic Analyzer)
* **기능 ID:** `FEAT-02`
* **우선순위:** **필수 (P0)**
* **설명:** 포트폴리오 장표별로 "왜 이 장표가 합격에 결정적이었는가?"를 설명하는 AI 분석 주석(Annotation)을 제공하는 인터랙티브 뷰어.
* **사용자 시나리오:**
  1. 유저가 특정 합격 포트폴리오 상세 페이지로 진입한다.
  2. 상단 슬라이더로 1페이지부터 순서대로 장표 이미지를 넘기며 열람한다.
  3. 우측(모바일은 하단 슬라이드 시트)에 Gemini AI가 분석한 **[① 문제 정의 방식]**, **[② 기획/기술 프레임워크]**, **[③ 정량적 성과 도출 논리]** 주석 카드가 장표와 실시간 동기화되어 표출된다.
* **세부 요구사항:**
  * 모바일 환경에서는 핀치 투 줌(Pinch-to-Zoom) 및 스와이프 제스처 지원.
  * 원본 장표 내 주요 영역 하이라이트 박스(Bounding Box) 오버레이 연동.

### 기능 3: 포트폴리오 전용 대화형 AI 챗봇 및 도메인 가드레일 (AI Chatbot with Guardrails)
* **기능 ID:** `FEAT-03`
* **우선순위:** **필수 (P0)**
* **설명:** 열람 중인 포트폴리오에 대해 궁금한 점을 질문하면 답변해 주는 특화 AI 챗봇. 단, 포트폴리오 및 직무/취업과 무관한 질문은 사전 차단하는 엄격한 예외 처리(가드레일) 탑재.
* **사용자 시나리오 (정상 질문 케이스):**
  * 유저 질문: *"3페이지 프로젝트에서 왜 A/B 테스트 대신 정성 인터뷰 방식을 택했는지 설명해 줘."*
  * 챗봇 답변: 포트폴리오 장표 데이터를 기반으로 해당 의사결정의 배경과 기획 로직을 명쾌하게 해설.
* **사용자 시나리오 (예외 / 포트폴리오와 관련 없는 질문 수신 시 동작):**
  * 유저 질문: *"오늘 테슬라 주식 살까?", "내일 서울 날씨 어때?", "유튜브 재미있는 영상 추천해줘", "연애 상담해줘"*
  * **챗봇 동작:** 임의의 답변 생성을 즉각 거절하고, 다음의 **표준 안내 문구**를 말풍선으로 단독 출력:
    > **"죄송합니다. 포토폴리오와 관련된 질문에만 답변할 수 있습니다."**  
    > *(부연 팁 카드: "현재 열람 중인 포트폴리오의 기획 의도, 문제 정의, 기술 스택 등에 대해 질문해 보세요.")*
* **AI 개발자 구현 가이드:**
  * **Gemini API System Instruction:**
    ```text
    당신은 FolioLogic의 합격 포트폴리오 전문 AI 멘토입니다.
    사용자의 질문이 제공된 포트폴리오 내용, 장표별 기획 의도, 프로젝트 성과, 직무 역량 및 취업과 직접적으로 관련이 없는 경우(예: 일상 잡담, 주식/금융, 날씨, 번역, 일반 지식, 엔터테인먼트 등),
    절대로 답변을 생성하지 마십시오.
    반드시 정확히 아래의 문장만을 단독으로 출력해야 합니다:
    "죄송합니다. 포토폴리오와 관련된 질문에만 답변할 수 있습니다."
    ```
  * 토큰 낭비 방지: 가드레일 조건에 걸릴 경우 1문장(10토큰 내외)만 즉각 리턴하여 API 호출 비용 최소화.

### 기능 4: 특정 관리자 이메일 기반 접근 제어 (`/admin` RBAC)
* **기능 ID:** `FEAT-04`
* **우선순위:** **필수 (P0)**
* **설명:** 신규 포트폴리오 업로드, 장표별 메타데이터 및 AI 분석 결과 검수를 담당하는 관리자 페이지(`/admin`)에 대해, **사전에 지정된 특정 이메일로 로그인한 계정만 접근할 수 있도록 강제하는 엄격한 접근 제어**.
* **사용자 시나리오:**
  1. `admin@foliologic.com`과 같이 사전에 승인된 관리자 이메일로 로그인한 계정이 `/admin` URL에 접속하면 관리자 대시보드가 정상 렌더링됨.
  2. 일반 유저 계정, 승인되지 않은 구글 계정, 또는 비로그인 사용자가 브라우저 주소창에 `/admin`을 입력하여 접속 시도.
  3. Next.js Edge Middleware 레벨에서 요청을 즉시 가로채 세션 이메일을 검증한 뒤, **`403 Forbidden` 에러 페이지**를 띄우거나 메인 홈(`/`)으로 강제 리다이렉트 처리.
* **AI 개발자 구현 가이드 (Next.js Middleware 로직):**
  ```typescript
  // middleware.ts 예시
  import { createMiddlewareClient } from '@supabase/auth-helpers-nextjs';
  import { NextResponse, type NextRequest } from 'next/server';

  export async function middleware(req: NextRequest) {
    const res = NextResponse.next();
    const supabase = createMiddlewareClient({ req, res });
    const { data: { session } } = await supabase.auth.getSession();

    // /admin 경로 보호
    if (req.nextUrl.pathname.startsWith('/admin')) {
      const allowedEmails = (process.env.ADMIN_EMAILS || '').split(',').map(e => e.trim().toLowerCase());
      const userEmail = session?.user?.email?.toLowerCase();

      if (!session || !userEmail || !allowedEmails.includes(userEmail)) {
        return NextResponse.redirect(new URL('/403', req.url)); // 비인가자 원천 차단
      }
    }
    return res;
  }
  ```
  * **환경 변수 선언:** `.env.local`에 `ADMIN_EMAILS="admin@example.com,chick@gmail.com"` 형태로 등록 관리.
  * **Supabase DB 보안 (RLS):** 포트폴리오 등록/수정/삭제 테이블은 DB 레벨에서도 이메일 또는 `role = 'admin'` 확인 정책 적용.

### 기능 5: 포트폴리오 북마크 및 개인 맞춤 벤치마킹 메모장
* **기능 ID:** `FEAT-05`
* **우선순위:** **선택 (P1 - MVP 후반 도입)**
* **설명:** 관심 있는 합격작을 내 보관함에 스크랩하고, 내 포트폴리오에 적용할 아이디어를 장표별로 메모하는 기능.
* **사용자 시나리오:**
  1. 마음에 드는 포트폴리오 장표에서 `[⭐ 북마크]`를 누른다.
  2. '내 벤치마킹 노트' 팝업을 열어 "내 2번 프로젝트 문제 정의 부분에 이 프레임워크 차용하기"라고 메모를 남긴다.
  3. 마이페이지에서 북마크한 장표들과 메모만 한 번에 모아본다.
