## 1. 개요 (Overview)

### 1.1 프로젝트 이름
* **공식 명칭:** **FolioLogic (폴리오로직)**
* **한글 서브 브랜드:** **합격로그 (PassLog)**

### 1.2 한 줄 설명 (One-Liner)
> **"단순 디자인 감상을 넘어, 합격자의 기획 논리와 문제 해결 구조를 AI로 해부하고 대화하며 내 것으로 만드는 인터랙티브 포트폴리오 큐레이션 플랫폼"**

### 1.3 프로젝트 배경 및 목적 (Background & Objectives)
* **배경:**
  * 신입 취업 준비생(대학생, 부트캠프 수료생, 비전공자 등)은 서류 통과를 위해 양질의 포트폴리오 레퍼런스를 필요로 하지만, 실제 합격작은 고가의 유료 강의나 폐쇄적인 지인 네트워크 뒤에 가려져 있어 접근이 어려움.
  * 기존 디자인 갤러리(비핸스 등)는 시각적 디자인에 치중되어 있어 실제 면접관이 평가하는 '문제 정의 및 비즈니스 해결 로직'을 배울 수 없으며, 기존 취업 카페의 단편적인 합격 스펙 나열은 내 조건(비전공/무스펙 등)에 맞춘 핀포인트 벤치마킹을 제공하지 못함.
* **목적:**
  * 검증된 실제 합격 포트폴리오의 장표별 기획 의도와 핵심 성과를 **Google Gemini AI**로 분석하여 구조화.
  * 구직자가 본인의 배경과 가장 유사한 합격 사례를 추천받고, **포트폴리오 전문 대화형 AI 챗봇**과 문답하며 기획 논리를 체득할 수 있는 저비용·고효율 학습 플랫폼을 구축함.

## 2. 타깃 사용자 페르소나 (Target Personas)

### 페르소나 1: 김하은 (25세, 비전공 문과 출신 서비스 기획/PM 취준생)
* **상황:** 부트캠프에서 6개월간 팀 프로젝트를 마쳤으나, 서류 전형에 제출할 포트폴리오 장표를 어떤 논리 전개로 작성해야 할지 막막함.
* **니즈:** "나처럼 비전공 문과 출신으로 신입 기획자에 합격한 선배의 실제 장표를 보고, 문제 정의부터 성과 측정까지의 논리 흐름을 그대로 벤치마킹하고 싶다."
* **고충(Pain Points):** 비핸스에는 예쁜 앱 화면 디자인만 있고 기획 배경 설명이 없으며, 취업 컨설팅 1회 첨삭 비용은 30~50만 원에 달해 경제적 부담이 큼.

### 페르소나 2: 박준영 (27세, 컴퓨터공학 전공 신입 프론트엔드 개발자 구직자)
* **상황:** 개인 프로젝트와 깃허브 코드는 많지만, 채용 담당자 관점에서 '기술적 의사결정 이유(트러블슈팅)'를 설득력 있게 전달하는 포트폴리오 장표를 구성하지 못함.
* **니즈:** 서류 통과율이 높은 프론트엔드 합격 포트폴리오에서 어떤 기술 키워드와 문제 해결 과정을 하이라이트했는지 비교 분석하고 싶음.
* **고충(Pain Points):** 깃허브 링크만 제출했을 때 서류 탈락이 빈번하며, 개발자 친화적인 포트폴리오 레퍼런스를 찾기 어려움.

### 페르소나 3: 이지훈 (31세, 서비스 관리자 / 현직 시니어 PM)
* **상황:** 플랫폼의 관리자 계정으로 양질의 합격 포트폴리오를 지속적으로 업로드하고 데이터를 검수·관리하는 오퍼레이터.
* **니즈:** 간편하게 포트폴리오 이미지/PDF를 등록하고, AI가 자동 추출한 기획 논리 태그를 검수한 뒤 즉시 구직자에게 노출하고 싶음.
* **고충(Pain Points):** 일반 유저와 관리자 간의 권한 분리가 엄격하지 않으면 데이터 훼손이나 비인가 접근 리스크가 발생함.
